## Deploying (GitHub Pages)
Push to a public repo, then enable Pages: **Settings → Pages → Source: main / root**.
Your live URL appears there in a minute or two. We teach our Git workflow, so don't
sweat the mechanics — commit honestly as you go and share the live link + repo when done.

## Ground rules (short version)
- AI tools are allowed. If you ship it, you own it — verify before you trust.
- Don't over-build. Correct, responsive, well-reasoned beats big.
- Stuck on one piece? Note it in `DECISIONS.md` and move on.
